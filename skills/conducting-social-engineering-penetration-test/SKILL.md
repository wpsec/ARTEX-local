# 社工演练

> 改写自 Anthropic-Cybersecurity-Skills 的同名 Skill（上游 v1.0，作者 mahipal），适配 ARTEX 演练和报告流程。

1. 根据用户提供的演练目标、参与对象、渠道、时间安排和数据处理要求制定方案。
2. 选择任务所需的邮件、网页、电话或其他渠道，检查现有工具和运行条件，准备演练内容与基础设施。
3. 按任务要求执行演练，记录发送或交互事件、响应、关键时间和证据位置；处理账号、凭据或个人数据时遵循项目约定。
4. 汇总参与情况、发现的流程与控制缺口，区分已观察行为和推断。
5. 复盘有效路径、影响、清理结果及改进建议，形成 ARTEX 报告。
