# 云环境安全评估

> 改写自 Anthropic-Cybersecurity-Skills 的同名 Skill（上游 v1.0.0，作者 mahipal），适配 ARTEX 的资产和证据流程。

1. 根据任务提供的云平台、账户或项目、访问方式和测试目标梳理资源与身份边界。
2. 使用现有云 CLI、API、MCP 或配置导出枚举 IAM 策略、角色信任、网络入口、存储、服务端点和审计配置。
3. 关联身份、权限和资源关系，定位公开访问、过度授权、跨账户信任或可达管理面的风险。
4. 按任务目标验证实际权限和可利用路径，记录请求、响应、资源标识与产生的临时变更。
5. 清理测试创建的资源，并在报告中区分配置线索、已验证影响和云服务商责任边界。

从已有安全存储或任务配置获取必要的访问凭据；报告保留可复核的证据位置，处理敏感信息时遵循用户指定的保存和分享要求。
