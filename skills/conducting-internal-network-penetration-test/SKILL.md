# 内网与 AD 安全测试

> 改写自 Anthropic-Cybersecurity-Skills 的同名 Skill（上游 v1.0，作者 mahipal），适配 ARTEX 资产、发现和报告流程。

1. 根据任务提供的网络、接入点和身份信息梳理目标，记录已有条件及用户指定的约束。
2. 使用可用的扫描器、Shell、浏览器或 MCP 发现主机、端口与服务，记录版本、访问条件和响应证据。
3. 枚举网络分段、管理面、目录服务、域对象、信任关系、委派和权限；使用图谱工具串联潜在路径。
4. 依据任务目标验证服务弱点、身份配置和权限路径；需要时继续验证权限提升与横向移动。
5. 记录每一步的目标、命令或工具参数、实际响应、权限变化和环境影响；清理本次创建的临时资源。

报告应区分服务配置、已验证的影响和基于关系图推断的路径，并给出复现条件、证据与修复建议。
