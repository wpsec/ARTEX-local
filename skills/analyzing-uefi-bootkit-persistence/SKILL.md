# UEFI 与启动持久化分析

> ARTEX 改写自 Anthropic-Cybersecurity-Skills 的 analyzing-uefi-bootkit-persistence（上游 v1.0.0，作者 mukul975）。

分析用户指定的固件镜像、EFI System Partition 文件、变量转储或基线；任务需要时可采集设备固件和配置，保留原始数据及来源。

## 工作流程

1. 记录每个输入文件的来源、路径、大小和 SHA-256；保持镜像只读，分析产物写入独立目录。
2. 使用适当的解析器识别镜像格式、固件卷、模块和 EFI 可执行文件，记录工具版本及限制。
3. 检查启动链组件、EFI 分区内容、异常模块、签名状态以及 Secure Boot 配置或变量转储。
4. 使用适用的基线做版本或哈希比较，记录基线来源并验证厂商镜像的适用性和完整性。
5. 对可疑 EFI 应用、启动项和变量差异记录文件路径、偏移、哈希与判断依据；避免仅凭文件名归因。

## 输出

说明镜像类型、组件清单、异常位置、基线来源、启动持久化证据和分析限制。将检测到的差异与已确认的恶意植入区分开；涉及设备配置或固件修改时，按任务要求评估影响并保留可恢复的备份。
