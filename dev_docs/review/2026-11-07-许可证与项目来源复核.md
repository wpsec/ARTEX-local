## 发现与处理

- **来源声明不够明确：** README 先前只笼统称本项目为独立衍生版本，没有在显著位置说明其基于原始 ARTEX 源码修改、维护发布独立于原项目，并注明原项目作者及相关日期。已在 README 顶部补充声明，并新增 `NOTICE.md` 记录来源和修改状态。
- 根目录 `LICENSE` 为 GNU AGPL-3.0 正文；`web/LICENSE` 包含 MIT License 和 Mohammed Arham Khan 的版权声明。两份许可证文本均保留原样，并在 README 与 `NOTICE.md` 中说明其存在。
- README 原有“衍生作品必须同样以 AGPL-3.0 开源”的概括没有说明 `web/LICENSE` 的适用范围。已改为要求按具体材料适用的许可条款判断，避免在未确认范围时作笼统承诺。
