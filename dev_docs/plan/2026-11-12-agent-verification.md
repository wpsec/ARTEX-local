# ARTEX Agent 候选漏洞复核计划

## 目标与边界

提高独立渗透 Agent 和任务 planner/worker 的发现可信度。保留现有 Agent key、入口、工具及参数结构，不增加默认服务、MCP、Skill 或数据库字段。首轮评估 Web/API，所有实际探测限定在授权的隔离靶场。

## 实施状态

- 已在内置提示词中补充候选记录、独立复核、证据和任务间交接要求。任务模式的高危或证据存疑候选使用既有 fact 与复核意图。
- 已按当前提示词正文精确匹配升级旧默认值，保留自定义内容和版本历史；提示词写入与升级使用同一行锁。
- 已增加本地 Web/API 正负样本和隔离数据库回归检查；独立对话没有任务上下文时按现有提示工具交接。
- 待在同一模型与配置下分别运行旧版、新版的对话和任务流程，记录结果并核对负样本误报、证据、链路、覆盖、token 和耗时。

实现细节、样本预期与评测方法见 [Agent 复核说明](../dev/2026-11-12-agent-verification.md)。默认提示词是模型行为指导，不是对 `report_finding` 的强制校验，真实模型表现须单独评估。
