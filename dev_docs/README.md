# 开发文档

`dev_docs` 用于集中维护 ARTEX 的开发计划、实现说明、评审记录和项目历史。

## 目录

- [`plan/`](plan/README.md)：需求计划、阶段安排和待实施方案。
- [`review/`](review/README.md)：代码、设计和安全评审记录。
- [`dev/`](dev/README.md)：开发说明、架构记录和实现文档。
- [`history/`](history/README.md)：已完成计划、重要决策和历史记录。

## 维护约定

- 文档使用 Markdown，标题和正文默认使用简体中文，代码与产品术语保留原文。
- 文件名使用 `YYYY-MM-DD-主题.md`；持续维护的索引文件可使用固定名称，如 `README.md`。
- 活跃内容放在对应主题目录；计划完成或被新方案取代后，将其移入 `history/`，并保留原始日期和结论。
- 记录方案时写清目标、范围、关键决定和状态；评审记录同时注明结论及待处理项。
