# 【维护参考】分支模型

最后更新：2026-11-14

## 长期分支

- `main`：ARTEX-Pro 正式主分支，也是仓库默认分支。通过 Pull Request 接收完成审查的开发变更。
- `artex-dev`：日常开发分支。功能和修复在此开发、验证，再通过 Pull Request 合入 `main`。
- `artex-native-backup`：保留原生 ARTEX 源码基线，仅作追溯备份，不承接 ARTEX-Pro 日常开发。

## 工作流

- CI 在 `main` 与 `artex-dev` 的 push 和 Pull Request 上运行。
- 发布版本从 `main` 打 `v*` 标签，触发 Release 工作流。
- 不再使用 `artex-pro`、`artex-iteration` 或 `artex-iteration-dev` 作为长期分支。
- GitHub 远端保护规则需在仓库设置中单独配置；本地文档与 CI 工作流不会自动启用保护。
