## 待验证项

- Judge 默认关闭；新配置启用后失败动作显示为“人工审批”。旧库中明确保存的 `allow`、`ask`、`deny` 不被覆盖。
- Judge 遇到瞬时模型错误时最多重试一次；重试受 profile 配置及 15 秒 Judge 超时约束。确定性拒绝不应触发重试。
- Finding 原文引用在已绑定的 `proof`/`verification` 请求或响应正文中匹配时显示“引用原文已匹配”；引用错配显示未匹配；缺少合适 HTTP 证据时保持未核验。
- 增删、改用途或排序流量后，旧引用状态失效并重新核验；详情页和报告导出均说明原文匹配不等于漏洞确认。
- TCP 或没有 HTTP 快照的 finding 仍能登记，不因引用核验而失败。
- 删除单条和批量对话后，对应 transcript、附件、会话目录及 Noa 归档清理；有 Agent/旁路问题运行中的对话会先停止并排空。若数据库删除失败，暂存文件应恢复。
- Noa 默认关闭；本轮不以代码或容器构建结果推断其真实模型效果。
