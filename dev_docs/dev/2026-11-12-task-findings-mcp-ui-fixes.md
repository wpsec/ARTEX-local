# 任务发现与 MCP 统计界面修复

## 变更

- 将任务发现列表的“详情”改为更易点击的按钮，并在详情页保留任务上下文；返回时恢复原任务的“发现”页签。
- 任务详情的发现列表只展示当前任务自己的发现。关联任务仍可提供只读上下文，不再把其漏洞混入当前任务列表。
- 新建任务的关联任务选择器以任务名称为主标签；未命名任务回退到描述，描述和目标继续用于搜索。
- 核对 MCP 调用计数：截图中服务器总数为 13，`browser_navigate` 为 13，其余工具为 0，分项与总数相符，因此没有修改计数逻辑。
- 应用版本更新到 `2.2.1`。手工 Go 构建使用该版本号；发布构建仍使用构建参数注入的版本。

## 运行影响

本次只改源代码与开发文档。没有重启、重建或替换用户正在测试的容器；改动要进入运行实例，需要后续另行构建和发布。
