# 【待验证】CI 失败修复记录

## 改动

- 为 `Server` 和 `Engine` 增加有序关闭流程，确保任务循环、detached 意图执行、已准入操作、日志持久化和资产补全 worker 在 PostgreSQL 关闭前完成或停止。
- 修正 PostgreSQL JSONB 参数类型推断，并补齐自定义 `update_finding_report` schema 的证据版本字段。
- 交付报告生成前脱敏凭据，原始流量与证据留存不变。
- 在 Agent 概览中增加有界的任务授权范围摘要，使用限额查询和公司范围缓存，避免每轮加载完整范围表。
- 将 Go 最低版本提升到 1.26.11，并将 CI Go 包测试改为串行，避免测试共享数据库时互相干扰。
