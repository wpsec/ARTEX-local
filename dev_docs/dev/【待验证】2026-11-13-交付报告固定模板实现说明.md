# 【待验证】交付报告固定模板实现说明

## 目标与状态

将单漏洞交付报告固定为面向开发和业务人员的五节结构，补齐发现过程、失败尝试、定级依据、攻击链和 Burp 复现要求。格式由保存入口校验，内容必须依托真实证据；结构合格不代表漏洞结论或复现过程已经通过人工核验。

本轮源码已构建为本地 `0.3.17` 镜像并启动。已有任务报告不自动重写。真实模型报告质量和 Burp 实际重放均未验证。

## 固定结构与共享规则

`agent/delivery_report_template.go` 提供共享的章节顺序、保存指引和 `DeliveryReportWritingRules`。默认 Reporter 与兼容草稿生成接口使用同一份写作要求，避免两条路径各维护一套模板。

报告头保留一个非空一级标题、漏洞名称、完整 CVSS 4.0 Base 向量和测试时间。二级标题按顺序固定为“描述、修复、测试过程、攻击链路、证据说明”。必需三级标题如下：

| 所属章节 | 三级标题 |
| --- | --- |
| 描述 | 定级依据 |
| 测试过程 | 发现过程与攻击思路；失败尝试与未验证项 |
| 证据说明 | Burp 复现；复测标准 |

每项测试要求工具和参数、判据、时间、观察结果及证据引用。没有复现的结论标为“未验证”；失败尝试按执行记录说明，不补造失败，也不把未完成测试写成排除项。并发与重复提交使用实际业务读回和数量差分，不能仅凭成功状态码判定业务影响。

攻击链使用 `text` 代码块中的简短树形过程。修复建议只定位已检查的接口、源码、版本和配置；未知路径或版本明确标注，不能推测。面向使用者的完整规范见 [交付报告规范](../../docs/交付报告规范.md)。

## 保存校验与调用兼容

`server/delivery_report_template.go` 的 `validateDeliveryReportTemplate` 校验报告头、五个二级标题、必需三级标题和非空内容，并要求报告头向量与保存参数一致。Markdown 遍历忽略代码围栏及 HTML 注释中的伪标题，并检查围栏或注释是否闭合；行内 XSS 测试字符串中的注释符不会被当作实际 HTML 注释。

校验接入 `update_finding_report` 工具与 `saveFindingDeliveryReport` 的 HTTP PUT 保存路径，位于自动附包和写库之前。PUT 格式错误返回 400；工具返回可修正的格式反馈。格式错误不覆盖已保存报告。

沿用原生流程：`report_finding` 自动触发 Reporter，读取漏洞、执行记录和流量证据后，通过既有 `update_finding_report` 一次保存详细报告和交付报告。工具名、参数签名、编号约定及证据版本约束不变；不增加人工审批步骤。

兼容草稿接口继续返回 `cvss_vector`、`description`、`remediation`、`test_process`、`attack_chain`、`discovery_path` 六个 JSON 字段。具体发现过程、失败尝试和未验证项写入对应字段，允许简短树形攻击链。该接口不会从截断输入推测未提供的证据。

## 默认内容升级

`server/orchestration.go` 在启动时按已知旧内置默认提示词的精确哈希识别可升级记录，并将新版本保留在现有提示词历史中。用户编辑过的提示词不覆盖。默认触发语和工具说明按已知默认内容迁移，自定义描述、schema、工具绑定和启用状态继续保留。

保存期格式要求仍适用于自定义 Reporter 输出。若自定义提示词沿用旧格式，应按工具反馈调整；保留自定义内容不等于绕过格式校验。

## 流量附录与完整性

`appendDeliveryTrafficEvidence` 将已绑定材料附在现有“证据说明”内，使用三级及更低标题，不生成第六个二级标题。每个绑定的请求、响应相邻呈现，每个 `http` 围栏只含一条留存报文；编号、角色、真实采集时间、源流量、地址和用途放在围栏外。

附录明确平台头部经过整理，不补造缺失协议版本或报文头。正文继续从证据 blob 读取并校验哈希和长度。二进制材料以 Base64 表示时，说明需要还原字节，不能宣称直接粘贴文本即可重放。没有绑定流量不等于任务没有其他原始材料，报告仍须说明本机记录等材料的真实来源。

保留累计 4 MiB 的完整报文上限、证据版本冲突拒绝和损坏材料报错，不以截断片段代替完整包。旧附录通过独立 marker 替换；仅识别代码围栏外独立行 marker，避免响应正文中的同名文本截断报告。

## 前端评分兼容

`web/src/lib/delivery-report.ts` 统一处理新单行 CVSS 报告头，并继续识别旧三行信息。界面使用本地 `scoreCVSS4Base` 计算评分和等级，只改报告头，保留正文与 HTTP 围栏中的原文。
