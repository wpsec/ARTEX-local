## 发现与处理

### 中：任务详情混入只读来源任务的漏洞

任务详情页把 API 返回的 `inherited` 发现一起渲染，可能让来源任务的漏洞看起来属于当前任务。改为仅展示 `task_id` 与当前任务一致的发现；来源任务的只读继承能力仍保留在系统上下文中。

### MCP 调用数：未发现问题

截图中 browser MCP 累计 13 次，其中 `mcp__browser__browser_navigate` 为 13 次，其余工具为 0 次。工具分项合计与服务器总数一致，属于调用分布，不是计数 bug；本轮没有修改 MCP 计数代码。

### 低：关联任务选择器使用任务描述作为主标签

任务已有可选名称字段，但选择器只显示描述，名称信息被隐藏。现在名称优先，未命名时仍以描述兜底；详情和目标保留为辅助信息及搜索字段。

### 低：从任务发现打开详情后无法回到原位置

详情链接缺少任务上下文，返回按钮固定进入全局发现页。现在链接携带 `context_task`，详情页返回到该任务的发现页签；后端沿用已有的任务上下文校验。

### 低：详情入口点击区域过小

原入口是窄小的文字链接，已改为标准描边按钮。
